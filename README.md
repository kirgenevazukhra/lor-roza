# Сайт ЛОР-врача Латыповой Р. Г. — черновик на согласовании

Одностраничный сайт частнопрактикующего ЛОР-врача в Астане.
Принимает детей с рождения и взрослых. Запись идёт через WhatsApp.

**Черновик:** https://kirgenevazukhra.github.io/lor-roza/

Индексация закрыта (`noindex` + `robots.txt`) — черновик не должен
попасть в поиск раньше, чем сайт запустится на своём домене.

## Запуск

```bash
npm install
npm run dev -- --host     # локально и по сети, для просмотра с телефона
npm run build             # сборка в dist/
```

## Что где лежит

```
src/pages/index.astro     главная страница
src/pages/varianty/       сравнение шести пробных направлений
src/pages/proto/a…f       сами пробные направления
src/components/Photo.astro  адаптивные изображения (WebP + JPG)
src/data/*.json           цены, отзывы, услуги, вопросы, контакты
src/lib/site.js           доступ к данным и производные значения
public/images/            веб-версии фотографий, иконки, текстуры
scripts/                  обработка изображений и проверка вёрстки
```

## Как править содержимое

Всё изменяемое вынесено в `src/data/` — вёрстку трогать не нужно:

| Файл | Что внутри |
|---|---|
| `prices.json` | услуги и цены |
| `reviews.json` | отзывы из 2ГИС, рейтинг, дата выгрузки |
| `services.json` | направления, принципы, состав консультации |
| `faq.json` | вопросы и ответы |
| `contacts.json` | адрес, телефон, ссылки на WhatsApp, Instagram, 2ГИС |

После правки: `npm run build`, изменения уедут на Pages автоматически при push в `main`.

## Домен

Сейчас сборка настроена на путь `/lor-roza/`. Когда появится свой домен:

```bash
SITE_URL=https://ваш-домен SITE_BASE=/ npm run build
```

и убрать `noindex` в `src/pages/index.astro` вместе с `Disallow` в `public/robots.txt`.

## Чего в репозитории нет

Намеренно не опубликованы: оригиналы фотосессии в полном разрешении,
ответы врача из анкеты, внутренние рабочие документы и референсы.
Список — в `.gitignore`.

## Техническое

- Astro, статическая сборка, нулевой JavaScript по умолчанию
- Сайт полностью работает при отключённом JavaScript
- Вся анимация выключается при `prefers-reduced-motion`
- Цели нажатия не меньше 44px, горизонтального переполнения нет
- Формы сбора данных отсутствуют: весь поток идёт в WhatsApp,
  поэтому персональные данные сайтом не собираются
